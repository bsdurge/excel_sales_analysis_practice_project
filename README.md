# Coffee Sales Analysis | Excel

## Project Overview
This is a beginner practice project focused on analyzing coffee sales data using Microsoft Excel. The goal is to make sales performance easier to understand and help identify sales trends, top customers, and key markets.

## Business Problem
Businesses need a clear view of their sales performance to understand which products and markets generate the most revenue, identify high-value customers, and monitor changes in sales over time.

## Objectives
- Analyze sales trends over time.
- Identify the top 5 customers by sales.
- Compare sales performance across countries.
- Explore purchasing patterns across coffee types, roast types, and package sizes.
- Monitor key sales metrics through an interactive dashboard.

## Tools & Skills
- Microsoft Excel
- PivotTables and PivotCharts
- KPI cards
- Slicers and Timeline
- Data analysis and dashboard design

## Dashboard Features
- Total Sales
- Total Orders
- Total Quantity Sold
- Average Order Value
- Sales Trends Over Time
- Top 5 Customers
- Sales by Country
- Interactive filters for roast type, package size, and loyalty card status

## Key Business Value
The dashboard consolidates sales information into one interactive view, helping users monitor performance, compare markets, and identify customers and products for further investigation.

## Project Type
Beginner Practice Project

## Learning Outcome
Practiced using Excel to summarize sales data, build interactive visualizations, and communicate business information through a dashboard.
